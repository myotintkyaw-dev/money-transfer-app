# Money Transfer Tracker

A Firebase-powered money transfer tracking app built with React and Tailwind CSS.

## Features

- Email/password registration, login, logout
- Protected dashboard routes
- Firestore-backed transaction create, read, update, delete
- Dashboard totals for income, expense, and profit/loss
- Date filters for today, last 7 days, last 30 days, and custom ranges
- Firestore security rules so users can only access their own data
- Responsive UI with modular React structure
